To regenerate the current list after a build
(`KILN_API_URL=https://api.verscienta.com npm run build`):

```bash
cd dist/blog && for f in */index.html; do t=$(grep -o '<title>[^<]*</title>' "$f" | sed 's/<[^>]*>//g'); [ ${#t} -gt 70 ] && echo "${#t}  ${f%/index.html}"; done | sort -rn
```
